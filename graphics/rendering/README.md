# Отрисовка

`Render3D` — программная отрисовка 3D-тел в картинку с буфером глубины и определением грани под курсором. Не зависит от Qt и OpenGL, проверяется тестами `Render3D.*`.

Чертёж рисуется средствами Qt (`ui/widgets/ScenePainter.cpp`) по сцене из `graphics/scene`.

Отрисовки на видеокарте (OpenGL) пока нет: она понадобится для больших сборок.
