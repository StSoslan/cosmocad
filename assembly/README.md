# Сборки

Компоненты-ссылки на детали, сопряжения (совпадение, соосность, параллельность, расстояние, угол, касание), проверка пересечений, состав изделия. Тесты — `Demo.*`.

Компонентом может быть и другая сборка; есть измерение зазора.

Компонент можно пометить «не рассекать на разрезах».

Считается число свободных движений каждого компонента.

Нет: конфигураций, разнесённых видов.
