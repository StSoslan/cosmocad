# Установщик для Windows

Установщик собирается автоматически на серверах GitHub — файл `.github/workflows/installer.yml`.
Собирать его на своём компьютере не нужно.

## Как получить установщик

1. Откройте страницу проекта на GitHub, вкладку **Actions**.
2. Слева выберите **«Установщик для Windows»**, откройте верхний запуск с зелёной галочкой.
3. Внизу страницы, в разделе **Artifacts**, скачайте **CosmoCad-setup**. Внутри архива — файл
   `CosmoCad-<версия>-setup.exe`.

Сборка запускается сама после каждого изменения проекта; её можно запустить и вручную кнопкой
**Run workflow**. Первая сборка идёт около часа (собирается геометрическое ядро), следующие — 10–15 минут.

## Что делает сборка

1. Ставит Qt 6 и библиотеки (OpenCASCADE, nlohmann-json, GoogleTest).
2. Собирает программу и прогоняет все тесты.
3. Складывает программу, её библиотеки и данные в папку `stage`.
4. Проверяет, что сложенная программа запускается.
5. Собирает установщик программой Inno Setup по описанию `cosmocad.iss`.

## При первом запуске Windows может предупредить

Установщик не подписан цифровой подписью (подпись платная). Windows покажет окно «Система Windows
защитила ваш компьютер» — нажмите «Подробнее» → «Выполнить в любом случае».
