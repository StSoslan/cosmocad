# Трубы из полипропилена

Расчёт напорных труб из полипропилена PP-R, PP-RCT, PP-H и PP-B по ГОСТ 32415-2013: напряжение в стенке от внутреннего
давления, допустимое давление для класса эксплуатации, ожидаемый срок службы, наименьшая
толщина стенки. Умеет построить отрезок трубы как деталь.

Все числа (коэффициенты кривых длительной прочности, запасы, классы эксплуатации, размерный
ряд) лежат в `resources/libraries/pipes_pp.json`, там же записано, откуда каждое взято.
Как считается и откуда числа — в `docs/pipes.md`.
