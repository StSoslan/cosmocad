# Электрические схемы

Схема — это лист чертежа (рамка, основная надпись), на котором лежат объекты схемы: элементы
с выводами, проводники, метки цепей. Модуль считает цепи, выдаёт позиционные обозначения,
строит перечень элементов и проверяет схему. Показ, печать и экспорт идут через общий
механизм чертежа. Тесты — `Scheme.*`, `SymbolLibrary.*`.

Набор условных обозначений — `resources/standards/eskd/symbols.json`. В него включаются только
обозначения с подтверждёнными размерами; у каждого записан стандарт и чем размер подтверждён.
Сейчас их семнадцать; перечень и источники — `docs/standards/eskd-coverage.md`.

Команда «Номера цепей» ставит номер на каждую цепь без имени.

Нет: остальных обозначений, клемм и разъёмов.
