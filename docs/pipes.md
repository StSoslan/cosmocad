# Трубы из полипропилена: расчёт на внутреннее давление

Модуль отвечает на вопросы: выдержит ли труба заданное давление, какое давление для неё
допустимо, сколько она прослужит и какая стенка нужна. Материалы — PP-R, PP-RCT, PP-H и PP-B.
Ещё он строит отрезок трубы как деталь, которую можно вставить в сборку.

## Как пользоваться

- **В окне:** вкладка «3D» → **Труба PP…** Программа спросит материал, класс эксплуатации,
  диаметр, серию и давление, покажет расчёт и предложит добавить отрезок трубы в проект.
- **Из командной строки:** `cosmocad-cli pipe PP-R 1 25 6 0.6` — материал, класс, наружный
  диаметр в мм, серия SDR (или `стенка=4.2`), давление в МПа. `cosmocad-cli pipes` показывает
  материалы, классы и таблицу толщин стенок.
- **Из скрипта Python:** `project.pipe_check(25, 0.6, "1", sdr=6)` и `project.pipe(25, 1000, sdr=6)`.

1 МПа = 10 бар ≈ 10 атмосфер.

## Как считается

1. **Напряжение в стенке** от внутреннего давления: σ = p · (d − e) / (2e), где d — наружный
   диаметр, e — толщина стенки. Отношение (d − e) / (2e) называется серией S; SDR = d / e.
2. **Сколько труба выдержит** при постоянных температуре и напряжении — по эталонной кривой
   длительной прочности материала: lg t = A + B·lg σ / T + C / T + D·lg σ (t — часы,
   T — температура в кельвинах). У PP-R кривая из двух ветвей, берётся меньшее время.
3. **Класс эксплуатации** задаёт, сколько лет из 50 труба работает при рабочей, максимальной
   и аварийной температуре. Для каждого участка напряжение умножается на коэффициент запаса
   (1,5 при рабочей, 1,3 при максимальной, 1,0 при аварийной, 1,4 для холодной воды).
4. Участки складываются по **правилу Майнера**: доля ресурса, израсходованная на каждом,
   равна времени работы, делённому на время до разрушения. Допустимое напряжение — то,
   при котором ресурс кончается ровно за 50 лет. Для классов стандарта программа берёт это
   напряжение из его таблиц.
5. **Допустимое давление** = допустимое напряжение / S. **Наименьшая стенка** для давления p:
   e = p · d / (2σ + p).

Классы: 1 — горячая вода 60 °C; 2 — горячая вода 70 °C; 4 — тёплый пол и низкотемпературные
радиаторы; 5 — высокотемпературные радиаторы; ХВ — холодная вода 20 °C.

Все числа взяты из ГОСТ 32415-2013 и сверены с его текстом. Они лежат в
`resources/libraries/pipes_pp.json`, их можно поправить без переделки программы.

| Что | Где в стандарте |
| --- | --- |
| Классы эксплуатации 1, 2, 4, 5 и ХВ | таблица 5 (класса 3 в стандарте нет) |
| Коэффициенты запаса | таблица Г.1 |
| Уравнения длительной прочности PP-H, PP-B, PP-R, PP-RCT | приложение В, рисунки В.1–В.4 |
| Допустимые (расчётные) напряжения | таблицы Г.2–Г.5 |
| Наибольшие серии для давлений 0,4; 0,6; 0,8; 1,0 МПа | таблицы Г.2–Г.5 |
| Толщины стенок, диаметры 16–160 мм | таблица 1 |
| Правило Майнера | приложение Б |

Два правила стандарта, которые программа соблюдает:

- Труба для горячей воды или отопления должна ещё и держать **холодную воду под давлением
  1,0 МПа 50 лет** (п. 4.3.5, формула 7). В отчёте это отдельная строка.
- Для трубы из размерного ряда сравниваются **серии**: серия трубы должна быть не больше
  наибольшей допустимой, округлённой до 0,1 (п. 4.3.6).

Проверка: пример из самого стандарта — «Труба PP-R SDR 6 20×3,4 класс 2/0,8 МПа,
класс 5/0,6 МПа» — программа подтверждает, а на ступень большее давление отклоняет.

## Что осталось неясным

- **PP-R, класс 1.** В таблице стандарта допустимое напряжение 3,09 МПа, а по его же
  уравнениям получается 3,02 МПа. Программа берёт табличное значение — оно обязательное.
  Из-за этого для PP-R в классе 1 у самого предела срок «по формулам» выходит меньше
  50 лет; отчёт об этом предупреждает. Остальные 19 табличных значений сходятся с расчётом
  до 0,02 МПа.
- **Три ячейки таблиц серий** (PP-H класс 5 при 0,6 МПа; PP-RCT класс 1 при 0,4 и 0,8 МПа)
  отличаются от деления напряжения на давление на 0,1. Программа берёт значения таблицы;
  на выбор трубы из ряда это не влияет.
- **Поправка 2023 года** к стандарту не проверена: присланный файл — издание 2016 года.
- **Плотность 0,9 г/см³** — справочная, не из стандарта; нужна только для массы отрезка.

## Чего расчёт не учитывает

Гидроудар, изгиб и температурное удлинение, прочность соединений и фитингов, качество
сварки, армированные трубы (стекловолокно, алюминий) — для них расчёт ведёт производитель.
