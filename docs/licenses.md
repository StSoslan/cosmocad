# Сторонние библиотеки и их лицензии

Требование КАЧ-11: у каждой сторонней библиотеки записаны лицензия и вариант замены.
Новая библиотека не добавляется без строки в этой таблице.

**Сведения взяты из открытых источников и не заменяют проверку юристом**, которой требует
исходное ТЗ.

## Лицензия самого CosmoCad

Владелец проекта решил (10.11.2026): программа открытая, лицензия — **GNU GPL версии 3**
(`GPL-3.0-only`). Текст — `LICENSE`, пояснения — `COPYRIGHT.md`. Системы ключей и активации нет.

Что это значит:

- программу можно свободно использовать, изучать, менять и распространять;
- тот, кто распространяет программу или её изменённый вариант, обязан дать получателю исходный код
  на тех же условиях;
- код CosmoCad нельзя включать в закрытые программы.

Совместимость библиотек с GPL 3:

| Библиотека | Лицензия | Совместима с GPL 3 |
| --- | --- | --- |
| Qt 6 | LGPL 3 | да |
| OpenCASCADE | LGPL 2.1 с исключением | да (LGPL 2.1 разрешает применять условия GPL версии 2 и более поздних) |
| nlohmann/json | MIT | да |
| oneTBB | Apache 2.0 | да (с GPL 3; с GPL 2 — нет) |
| GoogleTest | BSD (3 пункта) | да; в поставку не входит |

Выбор GPL 3 открывает возможность читать файлы DWG через библиотеку LibreDWG (тоже GPL 3).
Она пока не подключена.

## Используются сейчас

Скрипты на Python используют только стандартную библиотеку Python (лицензия PSF) и запускаются отдельным
интерпретатором пользователя; в поставку Python не входит. Решатель ограничений эскиза — собственный код.

| Библиотека | Версия при проверке | Зачем | Лицензия | Условия | Чем заменить |
| --- | --- | --- | --- | --- | --- |
| Qt 6 (Widgets, Gui, Core, PrintSupport) | 6.4.2 | Окна, рисование, PDF, печать | LGPLv3 либо коммерческая | Под LGPL: подключать отдельными заменяемыми библиотеками, дать пользователю возможность заменить Qt, приложить тексты лицензий. Не использовать модули Qt, доступные только под GPL | Коммерческая лицензия Qt |
| nlohmann/json | 3.11.3 | Чтение и запись JSON | MIT | Ограничений нет; сохранить уведомление об авторских правах | Любая библиотека JSON |
| GoogleTest | 1.14.0 | Тесты; в поставку не входит | BSD (3 пункта) | В продукт не попадает | Любая библиотека тестов |
| OpenCASCADE (OCCT) | 7.6.3 | 3D-геометрия, STEP, STL | LGPL 2.1 с исключением OpenCASCADE (по файлу `copyright` пакета Ubuntu) | Подключать отдельными заменяемыми библиотеками (так и сделано: OCCT виден только адаптеру); приложить текст лицензии | Коммерческое ядро (РЕШ-1) |
| oneTBB | 2021.11 | Нужен библиотекам OCCT из пакетов Ubuntu | Apache 2.0 (по файлу `copyright` пакета Ubuntu) | Сохранить уведомления; ограничений для закрытого продукта нет | Сборка OCCT без TBB |
