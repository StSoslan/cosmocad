# CosmoCad 0.15.0 — быстрый старт

## Запуск

```
build/release/ui/cosmocad                      пример чертежа
build/release/ui/cosmocad путь/проект.cosmocad  открыть проект
```

При запуске без параметров открывается пример: пластина с отверстием на листе А4 по ЕСКД.
Пустой лист: **Файл → Новый чертёж**.

## Окно

Вверху — **лента команд** с вкладками: «Файл» (открыть, сохранить, экспорт, печать, отмена),
«Главная» (черчение, правка, размеры, слои, проверка), «Схема», «3D», «Вид». Слева — панель
«Свойства», справа — «Слои», внизу — замечания проверки. В самой нижней строке — **вкладки
чертежей проекта** (кнопка «+» добавляет чертёж) и **поле команды** для ввода координат.
Справа поверх чертежа — кнопки «показать всё», «ближе», «дальше».

- **Колесо мыши** — масштаб вокруг курсора.
- **Правая или средняя кнопка с движением** — сдвиг чертежа.
- **Home** — показать лист целиком.

## Инструменты

| Кнопка | Как пользоваться |
| --- | --- |
| Выбор | Щелчок — выбрать элемент. Протяжка мышью — выбрать рамкой всё, что попало в неё целиком. Shift — добавить к выбранным. Ctrl+A — выбрать всё. Delete — удалить |
| Отрезок | Щелчок — начало, щелчок — конец; следующий отрезок продолжается от конца. Esc — закончить |
| Прямоугольник | Два щелчка — противоположные углы |
| Окружность | Щелчок — центр, второй щелчок — точка на окружности (или радиус числом) |
| Дуга | Центр, начало, конец. Дуга идёт от начала к концу против часовой стрелки |
| Текст | Щелчок — место текста; затем программа спросит сам текст и высоту шрифта |
| Размер | Два щелчка — измеряемые точки, третий — где провести размерную линию |
| Радиус, Диаметр | Щелчок по окружности или дуге, второй щелчок — в какую сторону направить стрелку |
| Выноска | Щелчок — куда указывает стрелка, второй щелчок — место излома; затем программа спросит текст |
| Шероховатость | Щелчок по линии поверхности, выносной линии или полке выноски; затем программа спросит вид знака и значение («Ra 3,2», «Rz 50»). Знак без значения можно поставить с любой из четырёх сторон линии |
| Блок из выбранного… | Собирает выбранные элементы в блок: они заменяются одной вставкой. Базовая точка — левый нижний угол выбранного |
| Вставить блок… | Ставит ещё одну вставку блока: место, поворот |
| Разбить блок | Превращает выбранную вставку обратно в обычные линии |
| Технические требования… | Пронумерованные требования над основной надписью: каждый пункт с новой строки, без номеров. Пустое поле убирает их |
| Шероховатость листа… | Общий знак в правом верхнем углу: значение и, если на изображении есть другие знаки, знак в скобках. Пустое значение убирает знак |
| Угол | Вершина угла, точка на первой стороне, точка на второй стороне, место размерной дуги. Угол отсчитывается от первой стороны ко второй против часовой стрелки |
| Штриховка | Сначала выбрать линии, которые замыкают область (и окружности-отверстия внутри), затем нажать «Штриховка» и задать расстояние между линиями |
| Перенос | Сначала выбрать элементы. Затем щелчок «откуда» и щелчок «куда» |
| Копия | То же, что перенос, но исходные элементы остаются. Можно поставить несколько копий подряд; Esc — закончить |
| Поворот | Выбрать элементы; щелчок — центр поворота; второй щелчок задаёт направление (или угол в градусах числом) |
| Отражение | Выбрать элементы; два щелчка — точки оси отражения |
| Обрезка | Щёлкнуть по лишней части отрезка — она удалится до ближайших пересечений с другими линиями |
| Скругление | Щёлкнуть по двум отрезкам угла — с той стороны, которую нужно оставить. Радиус: набрать число в поле ввода до щелчков (изначально 5 мм). Радиус 0 — просто свести отрезки в острый угол |
| Фаска | Так же, как скругление; число — размер среза по каждой стороне |

Во время рисования курсор притягивается к точным точкам. Оранжевый значок показывает, к чему:
квадрат — конец отрезка, треугольник — середина, кружок — центр, крестик — пересечение,
перевёрнутая «Т» — перпендикуляр, «песочные часы» — ближайшая точка на линии.

## Ввод с клавиатуры

Поле в правом нижнем углу окна заменяет щелчок мышью. Наберите и нажмите Enter:

| Что набрать | Что это значит |
| --- | --- |
| `100 50` | Точка: X = 100 мм, Y = 50 мм. Начало координат — левый нижний угол листа |
| `@20 0` | Точка на 20 мм правее предыдущей |
| `25` | Радиус окружности (после центра), угол поворота в градусах (после центра поворота), радиус скругления или размер фаски (до щелчков по отрезкам) |

Дробную часть можно отделять точкой или запятой: `70,5`.

## Свойства: правка уже созданного

Панель «Свойства» справа. Выберите один элемент — в панели появятся его свойства, и их
можно изменить:

| Элемент | Что можно изменить |
| --- | --- |
| Любой | Слой |
| Текст, выноска | Сам текст, высота шрифта |
| Окружность, дуга | Радиус |
| Линейный размер | Отступ размерной линии, высота шрифта, допуск |
| Размер радиуса или диаметра | Радиус ↔ диаметр, высота шрифта, допуск |
| Угловой размер | Высота шрифта |
| Штриховка | Расстояние между линиями, наклон |

**Допуск у размера** — три поля. «Допуск / посадка» пишется сразу после числа: `H7`, `±0,1`.
«Верхнее» и «Нижнее отклонение» пишутся мелко справа от числа, одно над другим: `+0,2`
и `−0,1`. Программа не проверяет, верен ли допуск, — она только рисует то, что вы ввели.

Правка применяется по Enter или при переходе в другое поле и отменяется как любое действие.

## Слои

Панель «Слои» справа. Выделенный в списке слой получает все новые элементы; от слоя зависит
тип и толщина линии. Галочка у слоя — слой виден. Кнопка «Новый слой…» спрашивает имя и тип
линии. Кнопка «Выбранное — на этот слой» переносит выбранные элементы на выделенный слой.

## Лист и основная надпись

**Главная → Лист.** Формат листа, ориентация, толщина основной линии
и поля основной надписи. Поля со звёздочкой обязательны: без них проверка оформления
выдаст замечание.

## Отмена

**Ctrl+Z** — отменить, **Ctrl+Shift+Z** (или Ctrl+Y) — повторить. Те же команды — кнопками на вкладке «Файл».
В подсказке кнопки написано, какое именно действие будет отменено.

## Проверка оформления

Кнопка **«Проверить оформление»** сверяет чертёж с профилем ЕСКД. Замечания появляются
в нижней панели: что нарушено, номер правила, ссылка на пункт стандарта. Щелчок по замечанию
выделяет элемент на чертеже.

Попробуйте: нарисуйте отрезок за пределами рамки и нажмите «Проверить оформление».

## Сохранение

**Файл → Сохранить.** Проект сохраняется как каталог с расширением `.cosmocad`.
Открывать: **Файл → Открыть** и выбрать этот каталог.

Раз в две минуты несохранённая работа записывается в автосохранение. Если программа была
закрыта аварийно, при следующем открытии проекта она предложит его восстановить.

## Экспорт

**Файл → Экспорт.** Тип файла задаётся расширением имени: `.pdf`, `.svg` или `.dxf`.
PDF и SVG — в масштабе 1:1.

## Печать

**Файл → Печать** (Ctrl+P). Чертёж печатается в масштабе 1:1; размер бумаги берётся из формата
листа. В окне печати выберите принтер и бумагу того же формата. Печать идёт без полей:
если принтер не умеет печатать до края бумаги, рамка у края может обрезаться.

## Несколько чертежей

В проекте может быть несколько чертежей и схем. Они показаны вкладками в нижней строке окна;
кнопка «+» рядом с ними создаёт новый чертёж.

## Электросхема

Схема рисуется на обычном листе. Откройте пример — третья вкладка внизу, «Фильтр. Схема».
Команды — на вкладке ленты **Схема**.

1. **Элемент.** Выберите обозначение (резисторы, конденсаторы, катушка, предохранитель, диод, транзистор,
   контакты, элемент питания, заземление, амперметр, вольтметр, лампа) и положение (горизонтально,
   вертикально), нажмите «Элемент» и щёлкните на листе. Программа спросит номинал («10 кОм»)
   и сама даст обозначение: R1, R2, C1… Место выравнивается по шагу 5 мм.
2. **Проводник.** Щёлкайте точки по очереди; рядом с выводом курсор сам встаёт точно на него.
   Esc — закончить. Проводники соединены, если конец одного лежит на другом (ставится точка).
   Простое пересечение соединением не считается.
3. **Метка.** Щёлкните конец проводника и введите имя цепи («Вход», «Общий»). Метка показывает,
   что провод уходит за пределы схемы, — без неё такой конец считается ошибкой.
4. **Номера цепей** пишет номер у каждой цепи, у которой нет имени. Цепи с меткой не трогаются.
5. **Проверка** находит висящие проводники, неподключённые выводы, повторы обозначений.
   Замечания появляются в нижней панели; щелчок по замечанию выбирает виновника.
6. **Цепи** показывает, какие выводы соединены. **На лист** ставит таблицу перечня элементов
   над основной надписью; нажмите ещё раз после правки схемы — таблица обновится.
   **Перечень** сохраняет его таблицей для Excel. **Перенумеровать** выдаёт обозначения заново, слева направо.
6. **Номинал…** меняет номинал выбранного элемента. **Сдвинуть…** двигает выбранные элементы
   вместе с присоединёнными проводниками. Обычный «Перенос» двигает элемент без проводников.

В наборе семнадцать обозначений по ГОСТ. Какие и по каким стандартам — в
`docs/standards/eskd-coverage.md`.

## 3D-модель

Окно 3D открывается кнопкой **Окно 3D** на вкладке ленты «3D» или клавишей **F3**. Откройте
пример (**Файл → Открыть пример**) — в нём есть деталь «Опора», деталь «Палец», их сборка
и чертёж опоры с видами по модели.

**Мышь в окне 3D:** левая кнопка — вращать, правая или средняя — сдвигать, колесо — масштаб.
Щелчок по грани выбирает её (она подсвечивается); одновременно выбрано не больше двух граней.
Кнопки «Спереди», «Сверху», «Слева», «Изометрия» показывают тело целиком.

### Как сделать деталь

1. В главном окне начертите замкнутый контур: прямоугольник, окружность или отрезки, концы
   которых сходятся по привязке. Окружность внутри контура станет отверстием.
2. Выберите контур (рамкой или «Выбрать всё»).
3. В окне 3D нажмите **Новая деталь**, затем **Выдавить контур**. Программа спросит, на сколько
   вытянуть контур вверх и на какой высоте лежит его плоскость.
4. **Вырезать контур** делает то же самое, но вычитает фигуру из тела. Чтобы просверлить плиту
   насквозь, вырежьте окружность на высоту не меньше толщины плиты.
5. **Скруглить ребро** и **Фаска**: щёлкните две грани, между которыми лежит нужное ребро,
   и нажмите кнопку.
6. **На грани…** — отверстие, паз, бобышка или выступ прямо на детали. Щёлкните плоскую грань
   в том месте, где нужен элемент, и нажмите кнопку. В окне выберите «вырезать» или «добавить»,
   окружность или прямоугольник, размеры и глубину. Координаты середины уже подставлены
   по месту щелчка (с округлением до 0,5 мм) — их можно поправить на точные числа или формулы.
7. **Размеры эскиза…** — выберите операцию в дереве и нажмите кнопку: откроется список размеров
   её фигур (положение, ширина, радиус). Любой можно заменить числом или формулой.
8. **Массив…** — выберите в дереве выдавливание или вырез и нажмите кнопку. «В ряд»: число копий
   и шаг по X и Y. «По кругу»: число копий и центр круга; копии раскладываются равномерно.
   Число копий может быть параметром (`n`): поменяли параметр — отверстий стало больше.

9. **Протяжка…** ведёт выбранный на чертеже контур вдоль траектории — так делаются прутки, трубы,
   гнутые профили. Траектория начинается в середине контура; введите её следующие точки через «;»,
   в каждой три числа через пробел (x y z): `0 0 50; 60 0 50` — вверх на 50, затем вбок на 60.
   Если у траектории есть изломы, задайте радиус гиба.

9. **Зеркало…** добавляет к детали её зеркальную копию. Выберите плоскость отражения (YZ, XZ или XY —
   они проходят через начало координат) и, если нужно, сдвиг плоскости в миллиметрах. Сдвиг может
   быть формулой с параметрами.

10. **Откат сюда** — выберите операцию в дереве и нажмите кнопку: деталь показывается такой,
   какой была после этой операции, остальные операции «ждут». Повторное нажатие снимает откат.

### Параметры

Кнопка **Материал…** открывает библиотеку материалов: начните печатать название в строке поиска,
выберите материал — он попадёт в основную надпись, а масса детали пересчитается по его плотности.
У каждого материала написано, откуда взята плотность. **Свой материал…** добавляет вашу запись:
она хранится в папке пользователя и видна во всех проектах. **Экспорт своих…** и **Импорт…**
передают свои материалы на другой компьютер файлом.

Кнопка **Исполнения…** запоминает нынешние значения всех параметров под именем
(«Короткое», «Длинное») и позже возвращает их одним действием. У исполнения может быть своё обозначение.


Параметр — это размер с именем: `длина = 80`. Размеры операций и другие параметры могут быть
формулами: `длина / 2`, `2 * ширина + 5 mm`, `max(a, b)`. Кнопка **Параметр…** добавляет
параметр. Чтобы изменить его, щёлкните дважды по ячейке «Формула» в таблице, введите новое
значение и нажмите Enter — модель перестроится. Если в формуле ошибка, внизу окна появится
объяснение, а модель останется прежней.

### Дерево построения

Список операций в порядке выполнения. Галочка включает и отключает операцию. Двойной щелчок
меняет её размер. Кнопка **Удалить** убирает выбранную операцию. Если операция не может
построиться (например, скругление больше детали), она помечается знаком ⚠ с объяснением,
а остальная модель продолжает работать.

### Сборка

1. **Новая сборка**, затем **Добавить компонент…** — выберите деталь или другую сборку.
   **Крепёж…** вставляет болт, гайку или шайбу из библиотеки: выберите вид, диаметр резьбы и длину.
   **Уголок…** добавляет отрезок стального равнополочного уголка ГОСТ 8509-93: выберите ширину и толщину
   полки и длину.
   **Швеллер…** и **Двутавр…** добавляют отрезок швеллера ГОСТ 8240-97 (серии П, Э, Л) или двутавра
   ГОСТ Р 57837-2017 по номеру профиля.
   **Труба PP…** считает полипропиленовую трубу на внутреннее давление (подходит ли, какое давление
   допустимо, сколько прослужит) и добавляет отрезок трубы в проект. Подробности — в `docs/pipes.md`.
   Изделие появляется в проекте как деталь с обозначением («Болт М12×60 ГОСТ 7798-70») и попадает в состав изделия.
   Первый компонент закреплён.
2. Щёлкните по одной грани на двух разных компонентах и нажмите кнопку сопряжения:
   **Совпадение** (плоские грани вплотную навстречу), **Заподлицо** (в одной плоскости),
   **Соосность** (цилиндрические грани на одной оси), **Расстояние…**, **Угол…** (плоские грани
   под заданным углом), **Касание** (цилиндрическая грань одного компонента ложится на плоскую грань другого).
3. **Разнести…** раздвигает компоненты, чтобы было видно, как изделие собирается: введите расстояние.
   Сопряжения и собранный вид не меняются; 0 собирает обратно. Пока сборка разнесена,
   **Вид на чертёж…** ставит разнесённый вид.
3. **Степени свободы** показывает, сколько движений осталось у каждого компонента: 6 — ничем
   не удерживается, 0 — положение определено полностью.
4. **Пересечения** показывает, врезаются ли детали друг в друга. **Зазор** измеряет расстояние
   между двумя компонентами: щёлкните по грани на каждом и нажмите кнопку. **Состав изделия** — перечень
   деталей с количеством и массой; **Состав в CSV…** сохраняет его таблицей для Excel.

Сборка хранит ссылки на детали: изменили деталь — она изменилась и в сборке.

### Чертёж по модели

Кнопка **Вид на чертёж…** ставит вид детали или сборки (спереди, сверху, слева и другие)
на чертёж, открытый в главном окне. Линии вида — обычные линии чертежа: к ним ставятся размеры.
Кнопка **Разрез на чертёж…** ставит разрез: модель рассекается плоскостью, часть перед плоскостью
убирается, срез штрихуется. Программа спросит, где провести плоскость: оставьте поле пустым —
она пройдёт через середину модели, или введите координату в миллиметрах вдоль направления взгляда. Над разрезом появляется надпись «А–А»,
а на соседнем виде той же модели — штрихи секущей плоскости со стрелками и буквами.

**Сечение на чертёж…** делает то же, но показывает только то, что попало в саму плоскость.
**Сдвинуть разрез…** переносит плоскость готового разреза или сечения на новую координату.

Валы, болты и шпонки на разрезах принято показывать целыми. Для этого в окне модели выберите
компонент сборки в дереве и нажмите **Не рассекать**, затем **Обновить виды**.

Если модель изменилась, а виды ещё не обновлены, программа пишет об этом в строке состояния
и в списке замечаний («Виды по модели устарели»).

После изменения модели нажмите **Обновить виды**: линии видов перестроятся на прежнем месте,
а размеры, поставленные на точки вида, переедут следом и покажут новые числа. Если модель
изменилась сильно (появились или исчезли элементы), часть размеров может потерять привязку:
программа сообщит, сколько их, и пометит их — такие размеры нужно поправить вручную.

### Экспорт

**STEP…** сохраняет точные тела для других CAD-систем, **STL…** — сетку для 3D-печати.

## Ограничения эскиза

Вкладка **Эскиз** превращает набросок «от руки» в точную фигуру. Нарисуйте отрезки и окружности
примерно, затем выбирайте их и нажимайте кнопки — программа сама подвинет линии.

- **Соединить концы** — выберите два отрезка: их ближайшие концы совместятся.
- **Горизонтально**, **Вертикально** — для каждого выбранного отрезка.
- **Параллельно**, **Перпендикулярно**, **Равны**, **Касание**, **Общий центр** — выберите два элемента.
- **Точка на прямой** — выберите два отрезка: ближайший конец одного ляжет на прямую другого.
- **Симметрия** — выберите три отрезка: два станут зеркальными относительно третьего; ось программа
  определяет сама.
- **Расстояние…** — между ближайшими концами двух отрезков или центрами двух окружностей.
- **Длина…**, **Радиус…**, **Угол…** — размеры. **Изменить размер…** задаёт новое значение, фигура перестраивается.
- **Закрепить** — элемент остаётся на месте, остальные подгоняются под него.
- **Состояние** показывает, определён ли эскиз полностью, сколько свободных движений осталось,
  и список ограничений. **Снять** убирает ограничения с выбранного.

Рядом с элементами показаны зелёные значки ограничений: «—» горизонтально, «|» вертикально, «∥», «⊥»,
«=», «⚓» закреплено, число — размер. В файлы PDF, SVG и DXF значки не попадают.

Размер можно задать формулой от параметров детали: откройте окно 3D, выберите деталь и в поле
размера введите, например, `длина / 2`. Изменится параметр — перестроятся размер на чертеже, контур
и тело, выдавленное из этого контура.

Если новое ограничение противоречит прежним, программа его не ставит и называет, с чем оно не уживается.
После любой правки чертежа фигура с ограничениями подгоняется заново. Готовый контур можно выдавить
в деталь кнопкой «Выдавить контур» в окне 3D.

## Чего пока нельзя

В 2D: менять координаты элемента числами (только переносом); рисовать сплайны и эллипсы;
обрезать дуги и окружности. Штриховка и размеры не перестраиваются
сами, когда меняется контур.

В 3D: рисовать мышью произвольный контур прямо на грани (на грань ставятся окружность
и прямоугольник, сложный контур берётся с чертежа); брать в контур дуги; отражать отдельную операцию (зеркало копирует всё тело); делать оболочку и переход между сечениями; делать ступенчатые и местные разрезы. Во время долгого перестроения
окно не отвечает.

В схемах: ставить обозначения, которых нет в наборе (симметричные тиристоры, переключающий контакт, трёхфазные трансформаторы и другие).
