# План тестирования

Результат 8 из раздела 14 исходного ТЗ.

## Правило

Функция без автоматического теста готовой не считается. Формат или стандарт без паспорта
и тестов поддержанным не объявляется.

## Как запустить

```
cmake --preset release
cmake --build --preset release
QT_QPA_PLATFORM=offscreen ctest --preset release
```

`QT_QPA_PLATFORM=offscreen` позволяет проверять окно на машине без экрана.

## Что проверено вручную при подготовке этой поставки

Эти проверки сделаны один раз и в автоматический набор не входят:

- Снимок окна, SVG и PDF просмотрены глазами: рамка, основная надпись, контур, осевые линии,
  размеры и текст на месте и совпадают между собой.
- PDF: одна страница 209,9 × 297,0 мм — формат А4 в масштабе 1:1.
- DXF открыт сторонней библиотекой `ezdxf`: версия AC1009, 35 отрезков, 7 текстов, 1 дуга,
  1 окружность; встроенная проверка библиотеки ошибок не нашла.
- Проверка запрета ИИ намеренно «провалена» подстановкой запрещённой зависимости — она
  сработала.
- Схемы Mermaid проверены разбором: 14 схем, ошибок нет.
- Основная надпись просмотрена в увеличенном PDF: сетка, подписи и поля на месте.
- Чертёж-образец (разрез втулки со штриховкой, фаской, скруглением и четырьмя видами размеров)
  просмотрен в PDF. Тест `ui_interaction` сохраняет его в `ui_sample.png` и `ui_sample.pdf`.

## Замеры (КАЧ-6)

Программа `build/release/tests/cosmocad_bench`, чертёж из 100 000 отрезков, та же машина:

| Операция | Время |
| --- | --- |
| Добавление одной транзакцией | 70–100 мс |
| Построение сцены | 44–54 мс |
| Проверка оформления | 72–101 мс |
| Выбор щелчком | 10–12 мс |
| Поиск привязки | 40–67 мс |
| Экспорт DXF | 269–341 мс |
| Сохранение | 333–436 мс |
| Открытие | 499–679 мс |
| Отмена добавления | 33–49 мс |

Диапазон — два запуска в разное время; на общей проверочной машине числа гуляют на треть.

Выводы. Открытие укладывается в порог 10 с с большим запасом. Сцена теперь строится только
после изменения документа, а не при каждой перерисовке. Но привязка по-прежнему ищется
перебором при каждом движении мыши (40–67 мс на 100 000 объектов) — нужен пространственный
индекс, этап 2. Скорость самой отрисовки не измерялась, поэтому порог «30 кадров в секунду»
не подтверждён.

Замер нашёл и две настоящие ошибки: построение сцены и отмена массовой вставки росли как
квадрат числа объектов (минуты на 100 000 объектов). Обе исправлены, добавлен тест
`Performance.LargeDrawingOperationsScaleLinearly`.

## Правила для новых тестов

1. Тест называет требование, которое проверяет (номер из технического задания).
2. Случайные данные — только с фиксированным зерном, чтобы сбой воспроизводился.
3. Каждая исправленная ошибка добавляет тест, который её ловит (КАЧ-2).
4. Для каждого вида проверки оформления — два теста: «нарушение найдено» и «на правильном
   чертеже замечаний нет». Лишние замечания — такая же ошибка, как пропущенные.
5. Для каждого формата обмена — проверка на случайно искажённых файлах.
