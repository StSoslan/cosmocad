# Паспорт формата: STEP

| | |
| --- | --- |
| Направление | Запись и чтение |
| Кто пишет и читает | Геометрическое ядро OCCT (`IGeometryKernel::exportStep`, `importStep`) |
| Что передаётся | Точные тела детали или всех компонентов сборки на своих местах |
| Что теряется | Дерево построения, параметры, имена граней, названия и цвета деталей, структура сборки (в файле — просто набор тел) |
| Прикладной протокол | Тот, что OCCT 7.6 пишет по умолчанию; какой именно — не проверялось |
| Чтение | Тело читается как единое целое; грани получают имена `<метка>/face/<номер>`. Вставить прочитанное тело в документ детали пока нельзя — чтение используется в тестах |

Проверено: тело после записи и чтения имеет тот же объём и то же число граней
(`Kernel3D.StepRoundTripKeepsVolume…`); сборка из двух тел читается с суммарным объёмом
(`Demo.StepExportOfAssemblyContainsBothBodies`); пустой, мусорный и побитый файлы не роняют программу
(`Kernel3D.BrokenStepFilesAreRejectedWithoutCrash`).

Не проверено: открытие записанных файлов в других CAD-системах.
