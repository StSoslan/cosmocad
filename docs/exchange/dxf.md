# Паспорт формата: DXF

| | |
| --- | --- |
| Направление | Чтение и запись |
| Версия при записи | ASCII DXF R12 (`AC1009`) |
| Версии при чтении | Любой ASCII DXF с секцией `ENTITIES`; двоичный DXF не читается |
| Код | `exchange/dxf/Dxf.cpp` |
| Тесты | `Dxf.*` в `tests/unit/test_exchange_storage.cpp`, `cli_end_to_end` |

## Запись

Записывается то же, что видно на экране и в PDF: элементы чертежа, рамка и основная надпись.

| Что | Как записывается |
| --- | --- |
| Отрезок, окружность, дуга | `LINE`, `CIRCLE`, `ARC`, координаты с 15 значащими цифрами |
| Текст | `TEXT`: высота, поворот, выравнивание по центру для размерных чисел |
| Размеры всех видов | Разобраны на отрезки, дуги и текст; как размеры в другой программе не редактируются |
| Выноска | Отрезки и текст |
| Допуски при размере | Отдельные тексты рядом с размерным числом |
| Штриховка | Отдельные отрезки; как штриховка в другой программе не редактируется |
| Слои | Таблица `LAYER`. Имена — латиница, цифры, `_`, `-`, `$` в верхнем регистре |
| Штриховые линии | Таблица `LTYPE`: тип `CC_PATTERN_n` на каждый вид штриха |

## Чтение

| Элемент DXF | Результат |
| --- | --- |
| `LINE`, `CIRCLE`, `ARC`, `TEXT` | Соответствующий элемент чертежа |
| Код группы 8 (слой) | Создаётся слой с этим именем |
| Любой другой элемент | Пропускается и подсчитывается; число пропущенных сообщается пользователю |

## Ограничения

- **Толщины линий не записываются:** в DXF R12 их нет.
- **Имена слоёв с кириллицей заменяются** на `LAYER_1`, `LAYER_2`…: R12 допускает только латиницу.
- **Текст записывается в UTF-8.** DXF R12 кодировку не объявляет; некоторые программы
  покажут кириллицу неверно. Проверка в AutoCAD и КОМПАС не проводилась.
- При чтении не поддерживаются: `LWPOLYLINE`, `POLYLINE`, `SPLINE`, `ELLIPSE`, `INSERT` (блоки),
  `HATCH`, `DIMENSION`, `MTEXT`, координаты Z, системы координат объектов.
- При чтении теряются: цвета, типы линий, толщины, поворот и выравнивание текста.
- Единицы считаются миллиметрами; заголовок файла не анализируется.

## Безопасность

Любой входной файл считается ненадёжным. Повреждённый файл даёт сообщение об ошибке.
Тест `Dxf.RandomlyCorruptedFilesNeverCrash` подаёт 2000 случайно искажённых файлов.

## Проверка сторонней программой

Экспортированный пример прочитан библиотекой `ezdxf`: версия распознана как AC1009, все
44 элемента на месте, встроенная проверка библиотеки ошибок не нашла. В AutoCAD, КОМПАС
и других программах файл не открывался — это нужно сделать до объявления поддержки.
