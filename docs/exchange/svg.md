# Паспорт формата: SVG

| | |
| --- | --- |
| Направление | Только запись |
| Версия | SVG 1.1 |
| Код | `exchange/svg/Svg.cpp` |
| Тесты | `Svg.ContainsSheetAndEscapesText`, `cli_end_to_end` |

## Что записывается

То же, что видно на экране: элементы чертежа, рамка, основная надпись.

| Что | Как |
| --- | --- |
| Размер | Ширина и высота листа в миллиметрах — масштаб 1:1 |
| Отрезок, окружность, дуга | `line`, `circle`, `path` |
| Толщины и штрихи | `stroke-width`, `stroke-dasharray` в миллиметрах |
| Текст | `text`, шрифт `sans-serif`; служебные знаки (`<`, `&`, кавычки) защищены |
| Цвет | Только вида `#rrggbb`; всё остальное заменяется чёрным |

## Ограничения

- Чтения SVG нет.
- Шрифт — тот, что найдёт программа просмотра; вид текста может отличаться от экрана.
- Слои не записываются.

## Проверка сторонней программой

Экспортированный пример преобразован в картинку библиотекой CairoSVG и просмотрен: совпадает
с окном программы и с PDF.
