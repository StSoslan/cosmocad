# Паспорт формата: PDF

| | |
| --- | --- |
| Направление | Только запись |
| Код | `ui/widgets/ScenePainter.cpp`, функция `exportPdf` (средствами Qt) |
| Тесты | `ui_smoke` |

## Что записывается

То же, что видно на экране, тем же кодом рисования.

| Что | Как |
| --- | --- |
| Страница | Одна, размером с лист, без полей — масштаб 1:1 |
| Линии | Векторные, с толщинами и штрихами в миллиметрах |
| Текст | Контурами (не шрифтом): выглядит одинаково везде, но не выделяется и не ищется |

## Ограничения

- Экспорт находится в модуле UI, потому что использует Qt. Консольная утилита PDF не пишет.
- Текст в PDF нельзя найти поиском.
- Многостраничных документов нет.
- Требования к архивным PDF (PDF/A) не выполняются.

## Проверка

Страница экспортированного примера: 209,9 × 297,0 мм (формат А4). Страница преобразована
в картинку программой `pdftoppm` и просмотрена: совпадает с окном программы и с SVG.
