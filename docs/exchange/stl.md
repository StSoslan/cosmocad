# Паспорт формата: STL

| | |
| --- | --- |
| Направление | Только запись |
| Вид файла | Двоичный |
| Что передаётся | Треугольная сетка поверхности детали или всех компонентов сборки |
| Точность | Отклонение сетки от поверхности не больше 0,05 мм |
| Что теряется | Всё, кроме формы: точные поверхности, единицы измерения (в STL их нет; числа — миллиметры), цвета |

Проверено: файл записывается и не пуст. Не проверено: открытие в программах подготовки 3D-печати.
