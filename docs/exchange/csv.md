# Паспорт формата: CSV (состав изделия)

| | |
| --- | --- |
| Направление | Только запись |
| Что передаётся | Состав сборки: позиция, обозначение, наименование, количество, материал, масса одной штуки и общая |
| Кодировка | UTF-8 с меткой в начале файла — русский текст правильно открывается в Excel |
| Разделитель | Точка с запятой; дробные числа — с запятой |
| Ограничения | Это не спецификация по форме ГОСТ: разделов («Детали», «Стандартные изделия») и формы из профиля нет |

Проверено: содержимое файла (`cli_end_to_end`, сценарий окна). Не проверено: открытие в Excel и LibreOffice.
