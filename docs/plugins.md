# Дополнения

Дополнение — отдельная библиотека, которая добавляет программе команды. Программа находит дополнения
при запуске; сбой дополнения её не роняет — она работает без него и показывает причину.

## Где лежат

Каждое дополнение — в своей подпапке с описью `plugin.json`:

- `plugins/` рядом с программой (после установки — `share/cosmocad/plugins/`);
- `plugins/` в папке пользователя (`~/.config/cosmocad`, в Windows — `%APPDATA%/CosmoCad`);
- папка из переменной окружения `COSMOCAD_PLUGIN_DIR`.

Чтобы выключить или снова включить дополнение, выберите в окне «Файл» → «Дополнения» →
**Включить или выключить…** Изменение действует со следующего запуска программы.
То же можно сделать вручную: вписать имя дополнения отдельной строкой в файл
`plugins-disabled.txt` в папке пользователя.

## Как посмотреть и вызвать

- В окне: вкладка «Файл», группа «Дополнения» — кнопка на каждую команду и «Список дополнений».
- В консоли: `cosmocad-cli plugins` — список; `cosmocad-cli plugin <команда> проект.cosmocad имя=значение`.
- В пакетном режиме и из Python: команда `{"do": "plugin", "command": "mass-report.csv", "args": {"path": "массы.csv"}}`.

## Пример из поставки

«Ведомость масс» (`plugins/mass-report`): команда `mass-report.csv` выдаёт таблицу объёмов и масс всех
деталей проекта; с полем `path` записывает её в файл CSV.

## Как написать своё

1. Папка `plugins/<имя>/` с описью:

   ```json
   { "id": "mass-report", "name": "Ведомость масс", "version": "1.0.0",
     "apiVersion": 1, "library": "cosmocad_plugin_mass_report" }
   ```

2. Библиотека с тремя функциями (образец — `plugins/mass-report/MassReport.cpp`):

   ```cpp
   extern "C" int cosmocad_plugin_api_version();                          // вернуть app::kPluginApiVersion
   extern "C" const char* cosmocad_plugin_initialize(app::IPluginHost*);   // nullptr — успех, иначе текст ошибки
   extern "C" void cosmocad_plugin_shutdown();
   ```

   В `initialize` дополнение регистрирует команды: имя команды начинается с имени дополнения и точки.
   Команда получает доступ к сервисам программы (`AppContext`) и поля вызова, возвращает текст для пользователя.

3. Сборка: в `plugins/CMakeLists.txt` строка `cosmocad_add_plugin(<цель> <папка> <исходники>)`.

## Ограничения

- Дополнение должно быть собрано тем же компилятором и из той же версии исходников, что программа.
  Совместимость проверяется по номеру версии интерфейса (`apiVersion`).
- Дополнение может добавить только команды. Новые типы объектов, форматы обмена и профили стандартов
  через дополнения пока не подключаются.
- Документ с объектами неизвестного типа открывается и сохраняется без потерь, но показать или изменить
  такие объекты программа не может.
- Дополнения с ИИ запрещены так же, как ИИ в самой программе.
