# CosmoCad

Универсальная инженерная CAD-система для Windows и Linux: 2D-черчение, параметрическое 3D,
сборки, чертежи по ЕСКД/ГОСТ, электрические схемы.

**Версия 0.20.2 — 2D-чертёж, 3D-деталь, сборка, виды по модели, электросхемы; интерфейс с лентой команд.** До полной системы,
описанной в техническом задании, далеко: из 96 требований выполнено 40, частично — 55.
Точный перечень: [docs/requirements-status.md](docs/requirements-status.md).

В CosmoCad нет и не будет искусственного интеллекта, машинного обучения и обращений
к ИИ-сервисам. Это проверяется автоматически при каждой сборке.

## Что работает

- Окно с чертежом: масштаб, сдвиг, выбор щелчком и рамкой.
- Рисование: отрезок, прямоугольник, окружность, дуга, текст, штриховка; шесть видов привязок;
  ввод координат с клавиатуры.
- Размеры: линейный, радиуса, диаметра, угловой; допуски и посадки; выноски.
- Панель свойств: правка уже созданных элементов.
- Печать в масштабе 1:1.
- Правка: перенос, копия, поворот, отражение, обрезка, скругление, фаска, удаление.
- Слои: панель слоёв, текущий слой, видимость.
- Отмена и повтор любого действия.
- Лист с рамкой и основной надписью по форме 1; формат листа и поля надписи задаются в окне.
- Проверка оформления по профилю стандарта со ссылками на пункты ГОСТ.
- Профили стандартов — файлы; профиль организации наследует ЕСКД.
- Сохранение и открытие проекта; защита от сбоев; автосохранение.
- Экспорт в PDF, SVG, DXF; чтение DXF.
- Консольная утилита для пакетной проверки оформления.
- Трубы из полипропилена PP-R, PP-RCT, PP-H и PP-B по ГОСТ 32415-2013: расчёт на внутреннее давление, допустимое давление и срок
  службы по классам эксплуатации, отрезок трубы как деталь ([docs/pipes.md](docs/pipes.md)).

- 3D-деталь: параметры с формулами, выдавливание, вырез, вращение, скругление, фаска;
  отверстие или выступ ставятся щелчком по грани; размеры эскиза правятся в окне;
  массивы в ряд и по кругу; зеркальная копия тела; протяжка вдоль траектории с гибами; откат дерева построения к любому шагу; исполнения детали;
  изменили параметр — модель перестроилась, ссылки на грани и рёбра сохранились.
- Сборка: детали и другие сборки ссылками, сопряжения (совпадение, соосность, параллельность,
  расстояние, угол, касание), подсчёт степеней свободы, разнесённый вид, проверка пересечений, измерение зазора, состав изделия в CSV.
- Ограничения эскиза на чертеже: параллельность, перпендикулярность, касание, равенство, размеры и другие;
  решатель подгоняет фигуру и считает степени свободы; размеры могут быть формулами от параметров детали.
- Дополнения: отдельные библиотеки добавляют программе команды (`docs/plugins.md`); пример — «Ведомость масс».
- Скрипты на Python: модуль `cosmocad` строит детали и сборки из своей программы (`docs/scripting.md`).
- Библиотека материалов с плотностями и их происхождением; свои материалы, поиск, обмен файлами.
- Библиотека крепежа: болты ГОСТ 7798-70, гайки ГОСТ 5915-70, шайбы ГОСТ 11371-78 — деталью в сборку.
- Прокат: уголки ГОСТ 8509-93, швеллеры ГОСТ 8240-97, двутавры ГОСТ Р 57837-2017 — отрезок деталью в сборку.
- Чертёж по модели: шесть основных видов с линиями невидимого контура, обновление по команде;
  размеры, поставленные на вид, переезжают за моделью; простой разрез и сечение со штриховкой и обозначением;
  программа сообщает, какие виды устарели.
- Экспорт 3D: STEP и STL.
- Электросхема: элементы с выводами, проводники, метки цепей; цепи, позиционные обозначения,
  перечень элементов таблицей на листе и в CSV, проверка схемы. В наборе семнадцать обозначений
  по ГОСТ (резисторы, конденсаторы, катушка, предохранитель, диод, транзисторы, контакты,
  элемент питания, заземление, амперметр, вольтметр, лампы).
- Интерфейс: лента с вкладками и значками, вкладки чертежей и поле команды внизу.

## Чего нет

лофта, сложных разрезов на чертеже, полного набора обозначений для схем, библиотеки профилей проката, дополнений,
расчётных и технологических модулей. Полный перечень — `docs/requirements-status.md`.

## Сборка

Нужны: компилятор C++20, CMake 3.24+, Ninja, Qt 6.4+ (модули Widgets и PrintSupport),
OpenCASCADE 7.6 (с TBB), nlohmann/json 3.11+, GoogleTest, Python 3.

### Linux (проверено на Ubuntu 24.04)

```
sudo apt-get install cmake ninja-build g++ qt6-base-dev libgl1-mesa-dev \
     libgtest-dev nlohmann-json3-dev python3 libtbb-dev \
     libocct-foundation-dev libocct-modeling-data-dev libocct-modeling-algorithms-dev \
     libocct-data-exchange-dev libocct-ocaf-dev libocct-visualization-dev
cmake --preset release
cmake --build --preset release
QT_QPA_PLATFORM=offscreen ctest --preset release
```

Запуск: `build/release/ui/cosmocad`.

Без Qt (только библиотеки, консольная утилита и тесты): `cmake --preset no-ui`. OpenCASCADE нужен в любом случае.

Окно 3D-модели открывается из главного окна: вкладка «3D» → «Окно 3D» или клавиша F3.

### Windows (сборка ещё не запускалась)

Установщик собирается автоматически на серверах GitHub: `.github/workflows/installer.yml` ставит
Qt 6 и библиотеки, собирает программу, прогоняет тесты и выдаёт `CosmoCad-<версия>-setup.exe`.
Как его скачать — в `packaging/windows/README.md`. Сборка под Windows пока ни разу не запускалась,
поэтому первый запуск может потребовать правок.

## Как устроен репозиторий

```
core/        основа: номера объектов, ошибки, документы, транзакции, отмена
geometry/    геометрия; граница с 3D-ядром
drawing/     объекты и сервис чертежа
standards/   профили стандартов и проверка оформления
graphics/    сцена, выбор, привязки
exchange/    DXF, SVG
storage/     формат .cosmocad
ui/          окна (единственное место, где есть Qt)
apps/        оконное приложение и консольная утилита
resources/   профили стандартов
tests/       тесты
docs/        проектные документы
scripts/     проверки: запрет ИИ, границы модулей, схемы
```

Каталоги без кода содержат `README.md` с номером этапа, на котором код появится.
Подробно: [docs/architecture/repository.md](docs/architecture/repository.md).

## Что делать дальше

1. Собрать и прогнать тесты под Windows.
2. Ответить на вопросы владельцу проекта в [docs/risks.md](docs/risks.md) — прежде всего
   о модели распространения: от неё зависит выбор библиотек и лицензии.
3. Довести этап 4 (базовый 2D CAD) и этап 5 (ЕСКД) по [docs/development-plan.md](docs/development-plan.md).
4. До начала 3D — прототип устойчивых ссылок на грани.
