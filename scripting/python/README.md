# Скрипты на Python

`cosmocad.py` — модуль для своих программ: строит детали и сборки, меняет параметры, выгружает STEP.
Ему нужна только стандартная библиотека Python; библиотек ИИ нет. Модуль собирает список команд
и передаёт его `cosmocad-cli batch`. Описание и список команд — `docs/scripting.md`.

- `examples/plate_with_bolts.py` — пример: плита с отверстиями, болты из библиотеки, сборка, STEP.
- `test_cosmocad.py` — проверка модуля; входит в набор тестов проекта (`python_scripting`).
