# Sketcher — ограничения эскиза и решатель

Ограничения ставятся на отрезки, окружности и дуги чертежа (`Constraint` — объект документа).
`SketchService` добавляет ограничение и сразу подгоняет геометрию; если оно противоречит имеющимся,
ничего не меняется, а ошибка называет мешающие ограничения. Тесты — `Sketch.*`.

Виды: закрепление, совпадение точек, горизонтальность, вертикальность, параллельность,
перпендикулярность, равные длины, равные радиусы, концентричность, касание (отрезок — окружность,
окружность — окружность), точка на прямой, симметрия, длина, радиус, расстояние, угол.

Решатель — метод Левенберга — Марквардта с численными производными. Он начинает с нынешнего положения
и ищет ближайшее, поэтому фигура не «прыгает». Число степеней свободы — число свободных чисел
минус ранг матрицы производных; лишние условия — число условий минус ранг.

Значение размера может быть формулой от параметров детали: формулу считает приложение
(`AppContext::syncSketches`) и передаёт число через `setValues`. Значки ограничений рисует окно чертежа.

Нет: ограничений на концы дуг.
